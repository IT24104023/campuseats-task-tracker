# CampusEats Task Tracker

Small demonstration repository for SE3090 Lab Practical 08. The project shows a clean GitHub Flow workflow, GitHub Issues, GitHub Actions CI, and secure coding practices.

## Project checks

The CI workflow runs on pushes to `main`, `feature/**`, and `chore/**`, and on pull requests targeting `main`. It verifies that this README exists and lists the repository files.

## Security note

Secrets must never be committed. Runtime credentials should be supplied through environment variables or a secrets manager.
